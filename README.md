# job-market-analysis
Beyond the Job Posting: A Data-Driven Framework for Evaluating Employers - An Applicant's Attempt to Reverse-Engineer the Hiring Market After Repeated Encounters with "Unfortunately..."


As a systems designer and trader, I became interested in evaluating employers using the same analytical methods used in market analysis. Rather than focusing solely on salary, this framework examines workforce growth, replacement hiring, attrition, retention, litigation indicators, and candidate probability of success.

Version 0.1 -  because some of the data (especially applicants, interview counts, and rejection counts) is not publicly reported and will need modeling rather than direct measurement.


Research Note: This document combines publicly reported workforce data with analytical estimates and opinion-based scoring models. Estimated values are intended for comparative analysis and should not be interpreted as official company statistics.
Methodology Section
Explanation of the process:
1.	Collect public workforce counts.
2.	Review layoff trends.
3.	Review public litigation and EEOC actions.
4.	Review employee review platforms.
5.	Estimate hiring funnels where data is unavailable.
6.	Score growth hiring versus replacement hiring.
7.	Compare candidate expected value.
